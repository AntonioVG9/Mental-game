# 🧠 Mental Game

![Mental Game](./assets/Banner_real2.png)

**Mental Game** es un sitio web profesional desarrollado para un proyecto real de **psicología del deporte**, orientado a presentar los servicios de un psicólogo deportivo y facilitar el contacto con potenciales clientes.

> **"Tu juego comienza en la mente."**

## 🌐 Proyecto

La web incluye información sobre el profesional, sus servicios y diferentes vías de contacto, con un diseño adaptado a ordenador y dispositivos móviles.

El proyecto combina **frontend, backend, SEO y despliegue web**, acercándose a un caso de uso real.

## ✨ Características

* 📱 Diseño responsive.
* 🧭 Navegación adaptada a móviles.
* 👤 Presentación del profesional y sus servicios.
* 📩 Formulario de contacto conectado a un backend.
* 💬 Integración con WhatsApp.
* 🔍 SEO y datos estructurados con Schema.org.
* 🌐 Open Graph para redes sociales.
* 📄 Aviso legal y política de privacidad.
* 🤖 `robots.txt` y `sitemap.xml`.

## 🛠️ Tecnologías

* **CSS3**

* **API REST**
